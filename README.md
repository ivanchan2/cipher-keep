# CipherKeep 密碼守護者

> 不必經過 App Store 或 Google Play，用瀏覽器打開就能安裝；資料只存在你的裝置上，斷網也能用。

CipherKeep 是一個以單一網頁實作的密碼管理器。所有密碼都在瀏覽器內，以你的「主密碼」加密後存放在本機。**沒有伺服器、不需要註冊帳號，也不會上傳任何資料。**

## 🎯 專案目的

市面上的密碼管理 App 大多必須透過 App Store 或 Google Play 下載。這代表你得仰賴商店審核與開發者帳號，也很難確認 App 實際做了哪些事。

CipherKeep 的目標是**繞過應用程式商店，讓任何人都能在自己的裝置上直接執行密碼管理工具**：

- **免上架、免審核**：以 PWA（Progressive Web App）技術開發，從瀏覽器就能「加入主畫面」，用起來和一般 App 一樣。
- **跨平台**：iPhone、Android、電腦都能使用同一份程式。
- **程式碼完全公開**：只有三個檔案，任何人都能逐行檢查它做了什麼。
- **資料留在本機**：不依賴任何雲端服務，第一次開啟後即使完全斷網也能使用。

## ✨ 功能特色

- 🔐 **本機端加密**：採用 AES-GCM 256 位元加密，金鑰由主密碼經 PBKDF2-SHA256（600,000 次迭代，符合 OWASP 建議）推導而來。
- 👆 **生物辨識解鎖**：可用指紋或 Face ID 解鎖（WebAuthn 通行金鑰 + PRF），不需上架、也能離線使用。第一次設定需要連網。
- ⏱️ **自動上鎖**：閒置 5 分鐘，或離開 App 超過 1 分鐘，就會自動上鎖。
- 📋 **剪貼簿自動清除**：複製密碼 30 秒後自動清空剪貼簿。
- 📴 **完全離線**：Service Worker 會快取所有資源，首次開啟後不再需要網路。
- 📱 **可安裝為 App**：加入主畫面後會以獨立視窗開啟，不會顯示瀏覽器網址列。
- 🗂️ **自訂群組**：可自由新增、重新命名、刪除分類，並用標籤快速篩選。
- 🔎 **即時搜尋**：依標題、帳號或備註快速找到項目。
- 🎲 **強密碼產生器**：採用密碼學安全亂數（`crypto.getRandomValues()`），長度可調整（6–64 字元），並可自選大小寫字母、數字與符號。
- 💾 **加密備份**：可匯出、匯入加密後的 JSON 備份檔，方便換機或保存。

## 📲 安裝到手機（不經過 App 商店）

先把專案部署到任何支援 HTTPS 的網址（見下方「部署」），然後用手機開啟該網址：

**iPhone / iPad（Safari）**
1. 點選下方的「分享」按鈕。
2. 選擇「加入主畫面」。
3. 主畫面會出現 CipherKeep 圖示，點選即可像一般 App 一樣開啟。

**Android（Chrome）**
1. 點選右上角的「⋮」選單。
2. 選擇「安裝應用程式」或「加到主畫面」。
   - 解鎖保險庫後，頁面右上角若出現「安裝 App」按鈕，也可以直接點它安裝。

> 💡 安裝完成後請在有網路時開啟一次，讓程式完成離線快取。之後即使開啟飛航模式也能正常使用。

## 🚀 部署與本機預覽

### 部署

只要把以下檔案與 `icons/` 資料夾放在同一個目錄，上傳到任何靜態網站空間即可（例如 GitHub Pages、Netlify、Cloudflare Pages）：

```
index.html
tailwind.css
manifest.json
sw.js
icons/
```

> ⚠️ 正式環境必須使用 **HTTPS**，否則瀏覽器不會啟用 App 安裝與離線功能。

### 本機預覽

直接雙擊 `index.html`（`file://`）雖然可以開啟，但不會啟用離線功能。請改用靜態伺服器：

```powershell
npx serve .
```

或

```powershell
python -m http.server 8000
```

接著用瀏覽器開啟終端機顯示的網址，例如 `http://localhost:8000`。

## 📖 使用說明

1. **建立保險庫**：第一次開啟時設定主密碼（至少 6 個字元），並再輸入一次確認。
2. **解鎖**：之後每次開啟，輸入主密碼即可解鎖。
3. **新增項目**：點選右下角的 `+`，填寫群組、標題、帳號、密碼與備註。
4. **上鎖**：點選右上角的鎖頭圖示，程式會立即清除記憶體與畫面上的資料。閒置或離開 App 一段時間後也會自動上鎖。
5. **備份**：到「設定備份」分頁匯出加密保險庫，並把檔案存放在安全的地方。
6. **生物辨識解鎖**：在**連網狀態下**到「設定備份」→「生物辨識解鎖」按「啟用」，依手機提示驗證指紋或 Face ID。之後鎖定畫面會出現「使用指紋 / Face ID 解鎖」按鈕，離線也能使用。
   - 需要 iOS 18 以上，或 Android 新版 Chrome（搭配 Google 密碼管理工具）。不支援的裝置會顯示提示，仍可用主密碼解鎖。
   - 啟用後仍請牢記主密碼：換機、匯入備份或停用生物辨識時都需要它。
   - 停用後，系統中名為「CipherKeep」的通行金鑰可到 iCloud 鑰匙圈或 Google 密碼管理工具中手動刪除。

## 🛡️ 安全性說明

- 加密後的資料存放在瀏覽器的 `localStorage`（鍵名為 `cipherkeep_encrypted_vault`）。
- 每個保險庫使用隨機的 salt（16 位元組），每次儲存都會產生新的 IV（12 位元組）。
- 舊版保險庫（80,000 次迭代）在解鎖時會自動升級為 600,000 次，舊的備份檔也仍然可以匯入。
- 頁面**不載入任何第三方腳本**：Tailwind 已預先編譯成本地 CSS，Font Awesome 以 SRI 驗證檔案完整性。
- 內容安全政策（CSP）禁止頁面對外連線，即使外部樣式遭竄改，也無法把資料傳出去。
- 生物辨識解鎖時，主密碼以裝置通行金鑰的 PRF 輸出加密後存在本機，沒有通過指紋或 Face ID 就無法解開。不支援 PRF 的裝置不會提供此功能，絕不以明文保存主密碼。
- 「清除保險庫」只會刪除 CipherKeep 自己的資料，不影響同網域的其他網站（例如同一個 GitHub Pages 帳號下的其他專案）。
- 匯出的備份檔同樣經過加密，必須使用原本的主密碼才能解開。
- **忘記主密碼就無法找回任何資料**：本程式沒有後門，也沒有重設機制。
- 清除瀏覽器的網站資料，或移除已安裝的 App，都會一併刪除保險庫。**請務必定期匯出備份。**

## 🧱 技術架構

| 項目 | 技術 |
| --- | --- |
| 介面 | HTML + [Tailwind CSS](https://tailwindcss.com/) v3（預先編譯為本地 CSS） |
| 圖示 | Font Awesome 6.4.0（SRI 驗證） |
| 字型 | Inter、Noto Sans TC |
| 加密 | Web Crypto API（PBKDF2 + AES-GCM） |
| 離線與安裝 | PWA：Web App Manifest + Service Worker |

```
cipher-keep/
├── index.html          # 應用程式主體（介面與所有邏輯）
├── tailwind.css        # 預先編譯的樣式
├── tailwind.config.js  # 重新產生 tailwind.css 用的設定
├── manifest.json       # PWA 安裝設定
├── sw.js               # 離線快取用的 Service Worker
└── icons/              # App 與主畫面圖示
```

> 修改介面的 Tailwind class 後，需要重新產生 `tailwind.css`：
>
> ```powershell
> npx tailwindcss@3 -c tailwind.config.js -o tailwind.css --minify
> ```
